## Games

- [Jurassic Balloon](/jurassic-balloon/) — Pilot a makeshift hot-air balloon through a prehistoric wilderness. Play the first five levels free in your browser.

## Software

- [NNG](https://nng.nanomsg.org/) — A lightweight, brokerless messaging library. See the NNG project for documentation, downloads, and TLS support.
- [Language extensions for Nova](https://nova.app/) — Open-source syntax support for C, D, and CMake in the macOS editor.

## Books

- [NNG Reference Manual](/books/nng_reference/) by Garrett D’Amore — The official reference for NNG, available in print and as an ebook.
- **Distributed Systems Mastery: An NNG Developer’s Guide** by Garrett D’Amore — A forthcoming guide to building distributed applications with NNG’s scalability protocols.
